# 01 — Sign up for AI services

> **Goal**: Create free accounts for Claude / ChatGPT / Gemini.
> **Time**: 15 min.

## Why all three?

Each model has different strengths:
- **Claude** — coding / long-document analysis (1M context)
- **ChatGPT** — popular, multimodal (images / video)
- **Gemini** — most generous free tier, integrated with Google ecosystem

Sign up for all three early so you can throw the same prompt at each and feel the differences yourself.

---

## ✅ Claude (claude.ai)

### Steps

1. Go to https://claude.ai
2. Click **Sign up** (top right)
3. Enter email (Gmail recommended) → check verification mail
4. Enter name / phone number
5. Enter SMS verification code
6. You land on the chat screen

### First prompt
```
Please respond in English.
Draw a red apple in ASCII art.
```

### Free tier
- ~100 messages/day (varies by model and time)
- Claude Sonnet 4.6 available
- Image attachments supported

---

## ✅ ChatGPT (chatgpt.com)

### Steps

1. Go to https://chatgpt.com
2. **Sign up** or **Log in**
3. Options: Gmail / phone / Microsoft / Apple
4. Gmail is fastest
5. Email verification → enter name
6. Chat screen

### First prompt
Same prompt:
```
Please respond in English.
Draw a red apple in ASCII art.
```

### Free tier
- GPT-4o (limited)
- GPT-3.5 unlimited
- DALL·E image generation (limited)

### Paid (optional)
- Plus $20/mo — generous GPT-4o, full GPT-5 access

---

## ✅ Gemini (gemini.google.com)

### Steps

1. Go to https://gemini.google.com
2. Sign in with Google account (immediate if you have Gmail)
3. **Accept terms of service** once
4. Land on chat screen immediately

### First prompt
Same prompt:
```
Please respond in English.
Draw a red apple in ASCII art.
```

### Free tier
- Gemini 2.5 Flash (1500/day)
- Gemini Pro (limited)
- Video analysis (not just images)

---

## 🔍 Compare — same question, three models

Once signed up, throw this at all three:

```
What's the average annual salary for a Korean office worker?
Cite sources.
```

Or:
```
Explain quantum computing to a 5-year-old in one line.
```

→ Comparing the answers reveals each model's personality:
- Claude — careful with citations / accuracy
- ChatGPT — intuitive / friendly
- Gemini — rich detail / Google Search integration

---

## 🚧 Common traps

### SMS verification doesn't arrive (Korea)
**Symptom**: ChatGPT / Claude phone verification code never delivered
**Fix**:
1. Wait 1–2 min
2. Try "Resend" once
3. Still nothing → use a different phone (family member's)
4. Or use email verification if available

### Korean IP blocked (rare)
**Symptom**: Page won't load at all
**Fix**: Turn on VPN (Cloudflare WARP free, the 1.1.1.1 app)
