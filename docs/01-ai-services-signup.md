# 01 — AI 서비스 가입

> **목표**: Claude / ChatGPT / Gemini 셋 다 무료 계정 만들기.
> **시간**: 15분.

## 왜 셋 다?

각 모델마다 강점이 다릅니다:
- **Claude** — 코딩 / 긴 문서 분석 (1M 컨텍스트)
- **ChatGPT** — 대중적, 멀티모달 (이미지 / 영상)
- **Gemini** — 무료 한도 가장 풍부, Google 생태계 통합

처음엔 셋 다 가입해서 같은 질문 던져보면 모델 차이를 빠르게 학습합니다.

---

## ✅ Claude (claude.ai)

### 가입 단계

1. https://claude.ai 접속
2. **Sign up** 버튼 클릭 (오른쪽 상단)
3. 이메일 입력 (Gmail 추천) → 인증 메일 확인
4. 이름 / 휴대폰 번호 입력
5. SMS 인증 코드 입력
6. 첫 채팅 화면 진입

### 첫 프롬프트
```
한국어로 답변해줘.
빨간색 사과를 ASCII 아트로 그려줘.
```

### 무료 한도
- 하루 ~100메시지 (모델/시기에 따라 다름)
- Claude Sonnet 4.6 사용 가능
- 이미지 첨부 가능

---

## ✅ ChatGPT (chatgpt.com)

### 가입 단계

1. https://chatgpt.com 접속
2. **Sign up** 또는 **Log in**
3. Gmail / 휴대폰 / Microsoft / Apple 가입 옵션
4. 가장 빠른 건 Gmail
5. 이메일 인증 → 이름 입력
6. 첫 채팅 화면

### 첫 프롬프트
같은 거 입력:
```
한국어로 답변해줘.
빨간색 사과를 ASCII 아트로 그려줘.
```

### 무료 한도
- GPT-4o (제한적)
- GPT-3.5 무한
- DALL·E 이미지 생성 (제한적)

### 유료 (선택)
- Plus $20/월 — GPT-4o 풍부, GPT-5 풀 액세스

---

## ✅ Gemini (gemini.google.com)

### 가입 단계

1. https://gemini.google.com 접속
2. Google 계정으로 로그인 (Gmail 있으면 즉시)
3. **이용 약관 동의** 한 번
4. 채팅 화면 즉시 진입

### 첫 프롬프트
같은 거 입력:
```
한국어로 답변해줘.
빨간색 사과를 ASCII 아트로 그려줘.
```

### 무료 한도
- Gemini 2.5 Flash 풍부 (1500/일)
- Gemini Pro 제한적
- 영상 분석 가능 (이미지뿐 아니라)


- Gemini — 풍부한 디테일 / Google 검색 통합

## 🚧 흔한 함정

### SMS 인증 안 옴 (한국 사용자)
**증상**: ChatGPT / Claude 가입 시 휴대폰 인증 코드 안 받음
**해결**:
1. 1~2분 기다려보기
2. "다시 보내기" 1회 시도
3. 그래도 안 오면 → 다른 휴대폰 (가족 폰)
4. 또는 이메일 인증 옵션 (있으면)

### 한국 IP 차단 (드문 케이스)
**증상**: 페이지 로드 자체 안 됨
**해결**: VPN 켜기 (Cloudflare WARP 무료, 1.1.1.1 앱)
